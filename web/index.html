Samarkan data pribadi sebelum dikirim

Tutup NIK, nama, alamat, nomor HP, dan rekening di foto KTP atau teks. Tambahkan watermark tujuan supaya fotonya tidak bisa dipakai ulang untuk pinjol atau penipuan.

🔒 Diproses 100% di perangkat Anda. Foto dan teks tidak pernah di-upload.

Pilih foto, seret ke sini, atau tempel (Ctrl+V).

Centang untuk menutup.

    Tutup manual

    Seret di foto untuk menutup bagian lain (foto wajah, tanda tangan, data yang terlewat).

    Watermark

    Teks: “Hanya untuk verifikasi · ”

    ⚠️ OCR bisa salah baca. Periksa pratinjau dan tutup manual bagian yang terlewat sebelum mengunduh.

    File hasil tidak menyimpan metadata lokasi/kamera (EXIF).

    Yang dikenali
    
      
    NIK, nomor KK, NPWP, nomor HP, nomor rekening (bila ada kata seperti “rek”, “BCA”, “a.n.”), kartu kredit/debit, nomor BPJS, email, serta isian berlabel seperti Nama, Alamat, RT/RW, Kel/Desa, Kecamatan, dan Tempat/Tgl Lahir.
    
      
    Untuk developer
    
      
    Mesin yang sama tersedia sebagai library Go, handler log/slog, dan CLI untuk membersihkan log:
    
      
    go install github.com/Emil-02/sensor/cmd/sensor@latest
kubectl logs api | sensor redact
